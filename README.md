# 💈 Por Um Fio — Barbearia

Projeto individual desenvolvido como atividade **MS2 Substitutiva**, com o tema **C — Barbearia ou salão de beleza**.

## 📋 Descrição

Site institucional da barbearia fictícia "Por Um Fio". A página apresenta os serviços oferecidos com seus respectivos preços (renderizados dinamicamente via JavaScript), uma galeria de fotos do espaço, uma seção "Sobre" contando a proposta do ambiente, e um formulário de agendamento de horário com modal de confirmação do serviço escolhido.

## 🛠️ Framework utilizado

- **Bootstrap 5.3.8**, instalado via `npm` (não via CDN).

## 🚀 Como instalar e rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Gi-Fonseca/ms2-sub-GiovanaFonseca

   cd ms2-sub-GiovanaFonseca
   
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Abra o arquivo `index.html` diretamente no navegador (ou use uma extensão tipo *Live Server*).

## ✅ Seções implementadas

- **Header / Navbar** — menu fixo com links de âncora para as seções da página
- **Hero** — chamada principal com botão de agendamento
- **Serviços & Preços** — cards gerados dinamicamente via JavaScript
- **Galeria de Fotos** — grid responsivo de imagens do espaço
- **Sobre o Espaço** — texto institucional
- **Agendamento** — formulário de marcação de horário
- **Modal de Confirmação** — confirma o serviço escolhido antes de prosseguir
- **Footer** — rodapé com identificação da barbearia
